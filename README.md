# 坦克大战 · Tank Battle

一个用纯 HTML + Canvas 写的坦克大战小游戏 —— **单个 `index.html`，零依赖、零构建、双击即玩**。

致敬 FC 经典《Battle City》（90 坦克）。守住底部的雄鹰基地，消灭所有来袭坦克。

## 玩法

- 玩家坦克从地图下方出生，保护底部的 **雄鹰基地**
- 敌方坦克从顶部三个出生点不断涌入，会追着你打，也会拆基地的护墙
- **基地被摧毁** 或 **生命耗尽** → 游戏结束
- 消灭当前关卡全部敌人 → 进入下一关，**分数与火力等级会继承**

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | `↑` `↓` `←` `→` 或 `W` `A` `S` `D` |
| 开火 | `空格` 或 `J` |
| 暂停 / 继续 | `P` 或 `Esc` |
| 静音 | `M` |
| 重开（结算界面） | `R` |

触屏设备会自动显示虚拟方向键和开火按钮。

## 地形

| 地形 | 说明 |
| --- | --- |
| 🧱 砖墙 | 可被打穿，**包括你自己的子弹** |
| ⬜ 钢墙 | 打不穿，除非火力升到满级 |
| 🌊 河流 | 坦克无法通过，子弹可以飞过 |
| 🌿 草丛 | 谁都能过，但会遮住坦克 |
| 🦅 雄鹰 | 基地，**被敌方子弹击中即失败** |

## 道具

击毁敌人有约 22% 概率掉落，靠近即可拾取：

| 图标 | 名称 | 效果 |
| --- | --- | --- |
| ★ | 火力提升 | 最多 3 级：加速子弹 → 双发 → 可打穿钢墙 |
| ♥ | 生命 +1 | 增加一条命 |
| ⛊ | 护盾 | 10 秒无敌 |
| ✹ | 全屏爆破 | 立即消灭场上所有敌人 |
| ⏱ | 时间静止 | 敌人冻结 6 秒 |

## 敌人类型

| 类型 | 血量 | 特点 | 分值 |
| --- | --- | --- | --- |
| 绿色 基础 | 1 | 普通 | 100 |
| 黄色 快速 | 1 | 移动很快 | 200 |
| 蓝色 火力 | 2 | 子弹极快、射速高 | 300 |
| 紫色 装甲 | 4 | 血厚，需要多次命中 | 400 |

关卡越往后，敌人数量、同屏上限、移动速度和射速都会提升。共 3 张手绘地图，通关后循环并保持难度递增。

```bash
python -m http.server 8000

```

## 实现说明

- 单个 HTML 文件，无任何外部依赖、无网络请求、无构建步骤
- 逻辑帧固定在 60 FPS（`requestAnimationFrame` + 累积器），渲染分辨率随 `devicePixelRatio` 缩放
- 音效使用 WebAudio 实时合成，不含任何音频文件
- 每关地图用纯文本字符画描述，直接写在源码的 `LEVELS` 数组里，改地图不需要碰任何逻辑代码：

  ```
  .  空地     B  砖墙     S  钢墙     W  河流
  G  草丛     E  基地     P  玩家出生点     X  敌人出生点
  ```

- 调试入口挂在 `window.TankBattle`（`Game` / `Input` / `LEVELS` 等），方便在控制台里调参

### 与原版的两点差异

1. **玩家自己的子弹打不爆雄鹰基地**，只会在上面弹开（敌方子弹照常可以摧毁）。
   原版允许自毁基地，但玩家出生点正对基地，随手开两枪就输掉，代价过大。
2. **满级火力**是"向前打穿两格并加宽一格"，而不是原版的整片 3×3 爆破 —— 避免一枪铲平整面护墙。
